# Astroverso Studio

Produção de vídeos curtos para o TikTok com IA, em containers (Podman). Tokens e IDs não ficam no código: vão no
`.env` de cada versão.

| Versão | Para que serve |
|---|---|
| [**version_2**](version_2/) | **Cortes de vídeos longos (atual).** Você manda o link de um vídeo do YouTube no Discord, a IA escolhe o melhor trecho, você aprova o roteiro e recebe o corte vertical com legendas. Pedidos de alteração também são feitos pelo Discord. |
| [**version_1**](version_1/) | **Vídeos narrados a partir de tendências (arquivada).** Busca o que está em alta no TikTok, gera ideias com nota, roteiro, narração e imagens, e monta o vídeo. Fica guardada como referência. |

## Como usar

Veja o README de [`version_2`](version_2/).

As duas versões rodam separadas (projetos, bancos e portas próprios) e podem ficar no ar ao mesmo tempo.
